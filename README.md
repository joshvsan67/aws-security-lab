# aws-security-lab
- Designed and implemented a hands-on AWS cloud security lab focused on identity management, security monitoring, threat detection, and defensive security operations. 
- Configured and hardened AWS services including IAM, CloudTrail, GuardDuty, VPC security controls, and S3 permissions while simulating real-world attack scenarios to validate detections and improve cloud visibility. 
- Integrated logging and monitoring workflows with SIEM tooling to analyze authentication activity, privilege escalation attempts, reconnaissance behavior, and suspicious cloud events. 
- Applied cloud security best practices aligned with least privilege, detection engineering, and incident response methodologies.

## Purpose
This lab was created for educational purposes to practice cloud security monitoring, IAM hardening, detection engineering, and threat hunting within authorized AWS resources.
